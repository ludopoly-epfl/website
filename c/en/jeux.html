Finding your game
At our game nights, you’ll notice that each box has a coloured sticker on it. They serve as visual indicators on which languages the game is in.

There are 4 different colours : a blue sticker means that the game is only in french, a red one means that the game is only in english, a black one indicates that the game is in both languages and a green one means that the game is in neither of these.
