ABRÉVIATION
c : computer mode
p : phone mode
fr : french
en : english

STRUCTURE
le code pour générer les pages web est dans build.py, il doit être run en local à chaques modifs du site web
le code qui intéragit avec les page web est dans script.js, il gère aussi les langues et modes
le style des pages web est répartit entre les 2 fichiers style.css, un pour les natels et un pour les ordis
le contenu des pages web est dans text.txt, il doit être mis à jour avant de run build.py
